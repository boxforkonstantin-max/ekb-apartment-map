# Design Direction

## Register
Product — инструмент повторного использования, не рекламный сайт.

## First Viewport
На desktop сразу видны фильтры, карта и начало списка квартир. На mobile сначала компактная шапка и фильтры, затем карта высотой около половины экрана и список.

## Visual Principles
1. Карта и реальные данные — главный визуальный материал.
2. Плотно, но спокойно: минимум декоративных контейнеров.
3. Цена и площадь читаются быстрее названия застройщика.
4. Финансовые ограничения формулируются рядом с цифрами.

## Typography
Системный sans-serif с табличными цифрами. Иерархия строится размером и насыщенностью, не декоративными шрифтами. Основной текст 14–16 px.

## Color
Тёплый светлый фон, тёмно-синий текст, бирюзовый для подтверждённых вариантов, охра для резервных и красный только для превышения/риска. Контраст не ниже WCAG AA.

## Layout
Desktop: верхняя панель фильтров, затем grid 58/42 — карта и список. Карточка деталей появляется поверх нижней части карты/списка без отдельного маршрута. Mobile: один столбец, фильтры прокручиваются горизонтально.

## Components
- Маркеры с ценой, а не безымянные булавки.
- Компактные строки вариантов, не сетка одинаковых промокарточек.
- Модальная карточка деталей с планировкой и источниками.
- Переключатель «карта / список» на узких экранах не нужен: оба блока остаются доступны последовательно.

## Responsive Rules
- Touch targets не меньше 44 px.
- Карта: 430–560 px desktop, 48vh mobile.
- Детальная карточка становится нижним листом на mobile.
- Длинные названия и финансовые выводы переносятся без горизонтального overflow.

## Motion
Только короткое появление карточки и подсветка выбранного маркера. Учитывать prefers-reduced-motion.

## Anti-AI-Slop Rules
- Нет градиентного hero, орбов, свечения и трёх абстрактных преимуществ.
- Нет вложенных карточек ради декора.
- Нет рекламных эпитетов и общего балла «надёжности».
- Скругление умеренное, тени только для всплывающего слоя.

## Preflight Checks
- Keyboard focus и Escape для детальной карточки.
- Все изображения имеют alt; ошибки загрузки дают понятную заглушку.
- Фильтры дают пустое состояние.
- Проверить 1440×900, 1024×768, 390×844 и 360×800.
- Нет ошибок консоли и битых официальных ссылок в исходных данных.
