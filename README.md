# Интерактивная карта квартир Екатеринбурга

Статический сайт для сравнения квартир в новостройках в радиусе 5 км от площади 1905 года: цена до 9,5 млн ₽, площадь от 30 м².

## Возможности

- интерактивная карта OpenStreetMap;
- фильтры по цене, площади, типу, отделке и подтверждённости;
- конкретные лоты и ориентировочные предложения разделены;
- планировки из официальных карточек;
- финансовый периметр и открытые показатели застройщиков;
- адаптивный интерфейс без backend и аналитики.

## Локальный запуск

```sh
python3 -m http.server 4173
```

Открыть `http://127.0.0.1:4173/`.

## Источники и ограничения

Данные проверены 18 ноября 2026 года. Цена и наличие не являются офертой. Координаты предназначены для отбора по радиусу; перед сделкой нужно сверить адрес корпуса, проектную декларацию, ДДУ и условия семейной ипотеки.

Сайт публикуется как GitHub Pages и доступен любому человеку со ссылкой. `noindex` снижает вероятность появления в поиске, но не является защитой доступа.
